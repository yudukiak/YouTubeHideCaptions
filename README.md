YouTube Hide Captions
=====

![YouTubeHideCaptions](https://raw.githubusercontent.com/yudukiak/YouTubeHideCaptions/master/assets/image.png)

YouTube の字幕表示をワンクリックで切り替えられる Chrome 拡張機能です。

## ダウンロード
https://chrome.google.com/webstore/detail/*

## 使い方
1. タイトルの上部にある「字幕」のチェックを外すと、字幕が消えます。わーい。
2. チェック状態はブラウザに保存され、次回以降も維持されます。
