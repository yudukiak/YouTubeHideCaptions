https://chromewebstore.google.com/detail/youtubehidecaptions/gbedfkkcbgnempabghcimkdijkljpban

https://addons.mozilla.org/firefox/addon/youtubehidecaptions/

## 日本語

YouTube の字幕表示をワンクリックで切り替えられる Chrome / Firefox 拡張機能です。

### 使い方
1. 動画・LIVE ページを開くと、タイトル上部の「字幕」のチェックを外すと字幕が消えます。わーい。
2. チェックを入れると、字幕が再表示されます。
3. チェック状態はブラウザに保存され、次回以降も維持されます。

## English

Toggle YouTube captions with one click. A Chrome / Firefox extension.

### How to Use

1. Open a video or live page, then uncheck "Captions" above the title to hide captions.
2. Check it again to show captions.
3. The checkbox state is saved in your browser and kept for next time.
